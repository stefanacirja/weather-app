# Weather App 🌦️

O aplicație modernă pentru afișarea vremii în timp real, cu suport pentru căutare după oraș, geolocalizare, istoric căutări și cache inteligent pentru performanță sporită.

## 🚀 Funcționalități

- Căutare meteo după oraș sau locația curentă
- Selectare unitate temperatură (Celsius, Fahrenheit, Kelvin)
- Selectare limbă pentru descrierea vremii
- Istoric căutări cu posibilitate de ștergere
- Cache inteligent pentru răspunsuri rapide și reducerea apelurilor către API
- UI modern și responsiv

## 🛠️ Tehnologii folosite

- HTML5
- CSS3 (design responsive)
- JavaScript (ES6+ modules)
- [OpenWeatherMap API](https://openweathermap.org/api)

## 📦 Instalare și rulare

1. Clonează sau descarcă acest repository.
2. Deschide `index.html` într-un browser modern (Chrome, Edge, Firefox etc).
3. Nu este necesară instalarea unui server sau a altor dependințe.
